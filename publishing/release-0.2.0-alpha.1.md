# Forever Vanguard 0.2.0-alpha.1 — test build

One-button mouseover raid-icon cycling. Mouse 4 is the default when free. Native settings
provide a hotkey picker, icon ordering and per-icon toggles; no toolbar or macro setup.

Out-of-combat use only. Pauses when Forever hides available icons. Skips marked mobs and
occupied icons, reserves attempted icons until a new batch, and stops instead of wrapping.

Client validation is pending. Do not publish as stable. No release was uploaded by this task.
